## Raccourcis de l’éditeur {#editor}
Sur macOS, utilisez **Cmd** à la place de Ctrl pour les commandes d’édition.
| Raccourci | Action |
| --- | --- |
| Ctrl+T / Ctrl+N | Nouvel onglet |
| Ctrl+Maj+N | Nouvelle fenêtre (bureau) |
| Ctrl+W / Ctrl+Maj+W | Fermer l’onglet / la fenêtre |
| Ctrl+Tab / Ctrl+Maj+Tab | Onglet suivant / précédent |
| Ctrl+O | Ouvrir des documents |
| Ctrl+S / Ctrl+Maj+S | Enregistrer / Enregistrer sous |
| Ctrl+1 / 2 / 3 / 4 | Live / Côte à côte / Brut / Lecture |
| Ctrl+B / I / U / E / K | Gras / italique / souligné / code / lien |
| Ctrl+Maj+X | Barré |
| Ctrl+Maj+1 / 2 / 3 | Titres 1 / 2 / 3 |
| Ctrl+Maj+8 / 7 / 9 / . | Puces / liste numérotée / tâches / citation |
| Tab / Maj+Tab | Indenter / désindenter une liste |
| Ctrl+F | Rechercher / remplacer |
| Ctrl+Maj+V | Coller du texte brut |
| Ctrl+clic | Ouvrir un lien |
| F1 / Maj+F1 | Manuel / aide sur la vue actuelle |
Les touches de fonction peuvent nécessiter **Fn** sur certains claviers.
## Dans le manuel {#reader}
Tab et Maj+Tab passent d’une commande à l’autre. Entrée suit le lien sélectionné. Échap réduit une image agrandie. Recherchez les pages dans le champ en haut ou avec Ctrl+K ; le sélecteur de langue conserve les identifiants de page entre traductions.
