## Editor shortcuts {#editor}
On macOS, use **Cmd** instead of Ctrl for editing commands.
| Shortcut | Action |
| --- | --- |
| Ctrl+T / Ctrl+N | New tab |
| Ctrl+Shift+N | New window (desktop) |
| Ctrl+W / Ctrl+Shift+W | Close tab / window |
| Ctrl+Tab / Ctrl+Shift+Tab | Next / previous tab |
| Ctrl+O | Open documents |
| Ctrl+S / Ctrl+Shift+S | Save / Save as |
| Ctrl+1 / 2 / 3 / 4 | Live / Side by side / Source / Reading |
| Ctrl+B / I / U / E / K | Bold / italic / underline / inline code / link |
| Ctrl+Shift+X | Strikethrough |
| Ctrl+Shift+1 / 2 / 3 | Heading 1 / 2 / 3 |
| Ctrl+Shift+8 / 7 / 9 / . | Bullet / numbered / task list / quote |
| Tab / Shift+Tab | Indent / outdent a list |
| Ctrl+F | Find / replace |
| Ctrl+Shift+V | Paste plain text |
| Ctrl+click | Open a link |
| F1 / Shift+F1 | Manual / help for the current view |
Function keys may require **Fn** on some keyboards.
## Inside the manual {#reader}
Use Tab and Shift+Tab to move between controls. Enter follows a focused link. Escape reduces an enlarged image. Use the top search field or Ctrl+K to find pages, and the language selector to switch translations without changing page IDs.
