CyMD is a Markdown notepad for notes, documentation and illustrated documents. The desktop app runs on Windows, macOS and Linux. The browser edition shares the editor, with [file and network limits](doc:troubleshooting#browser).

## Your first document {#getting-started}
1. Choose **New** or press **Ctrl+N** (Cmd on macOS).
2. Write a heading, a paragraph and a task list. **Live** shows the formatting without Markdown markers.
3. Click **Save**. Choose **.md** for plain text or **.cymd** to keep images and text together.
4. Close and reopen the saved file to check it before sharing.

## Find your way around {#interface}
The top row holds document tabs. The toolbar contains file operations and formatting, followed by language, line numbers, view selection and the documentation button. The bottom bar reports cursor position, word count and file encoding.

## Read this manual {#help}
Open **Help → CyMD documentation**, the book button, or **F1**. **Shift+F1** opens the section for the current view. In the desktop app, every page, screenshot and diagram is installed locally and works without Internet.
The language follows the app when help opens. You can switch French/English inside the reader. Missing content translations fall back to English.

Search for a word, use the contents list, or follow the links below. Reading positions are kept while navigating this reader session. Bookmarks, notes and theme preferences use local browser storage when available.

## Accessibility {#accessibility}
Use **Tab** to reach links and controls, **Enter/Space** to activate them, and the image's labeled zoom buttons when a mouse wheel is unavailable. Touch controls remain accessible. The reader also offers a high-contrast theme. No media autoplays in this manual.
